# 自动化边界：v3

本包交付了本地 runner，不再只是提示词。是否能在用户环境调用成功、离开入口回合后持续执行，仍须首次实测。

| 能力 | 本包状态 | 必要条件 / 限制 |
|---|---|---|
| 网页规划、任务合同、依赖队列 | 提供提示词和模板 | 默认写入/复用 GitHub Issues；无写权限时输出 Issue Draft |
| Codex 分类并调用 pi 或 Codex | 提供实际脚本 | 本地 CLI、现有认证、可信执行授权 |
| pi 完成后 Codex 自动接手 | 提供 | 等进程真正退出后新建 CLI 控制会话，不是旧 UI 消息 |
| Codex 等待期间不反复轮询 | 提供 | 外层 OS wait；控制器不查询进度或递归自启 |
| 同仓库单写入者 | 协作锁 | 只约束本 runner，所有相关 worktree 保守串行 |
| 独立审阅与 SHA 校验 | 提供 | 不证明远端检查或人工批准；关键证据缺失则不 PASS |
| 本地建分支/提交 | 有限接口 | 一次授权、显式 SHA/路径、可信 hooks；无任意 shell |
| 断点续办 | 提供 | pending 需检查孤儿进程；不承诺 exactly-once |
| GitHub Issue/PR/评论 | 由既有 Agent 能力按权限执行 | 无单独 GitHub API 客户端；缺权限就 handoff |
| GitHub 远端强制门禁 | 未实现 | 需 branch protection / ruleset / 可信 checks |
| 自动合并/部署 | 未实现且默认关闭 | 不能只把 auto_merge 开关改 true 就以为生效 |
| CI 完成/人工合并后自动唤醒 | 未实现 | PAUSE 后按需 resume，无自动远端轮询 |
| 原 Codex 桌面窗口自动收到结果 | 未实现 | 本包写本地回执；App Server 集成需另建 |
| 跨机器或云端调用用户本地 pi | 未实现 | 本方案要求同一已授权本地环境 |
| 读取余额和自动切账单/模型 | 未实现 | 继承现有配置，不猜套餐权益 |

AGENTS 是行为规范，不是沙箱或守护服务。[S2] pi 本地工具具备文件/shell 权限，来源不明的仓库代码、扩展、测试 hooks 都可能执行本地操作，不能仅凭“AI Flow 已安装”视为安全。[S5]

详见 RUNNER.md。源码可审查、测试可重跑；本次提供的是经过模拟回归验证的接入包，不是已经在用户电脑完成部署的服务。

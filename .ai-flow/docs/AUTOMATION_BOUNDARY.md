# 自动化边界

已实现：本地单 coordinator、持久 Codex App Server/Pi RPC、分级路由、结构化结果、独立 SHA 审阅、完成事件续办、有限本地 Git、错误/取消、状态快照、Git 产物守卫。
没有实现：当前桌面聊天自动附着、Pi 桌面子 Agent 卡片、远端 CI/合并的自动唤醒、无人工批准的合并/部署、跨机器队列服务、OS 级 Pi 沙箱。

原生协议仍使用本机子进程。持久进程并非系统服务；运行暂停/结束时收起。宿主、休眠/关机、网络和认证仍可能中断。
升级不改变计费或现有账户；doctor --live 会消耗实际模型额度。第三方扩展可访问本机，必须可信。

stop --now 发送原生取消，必要时终止本 runner 自己的子进程；不撤销已生效的修改。崩溃 pending 不自动重放，不提供 exactly-once 承诺。
状态文件/PID 不是授权依据，不以旧 PID 自动杀任意进程。活动状态看明确的协议 thread/turn/session 与对应完成事件。

本地 Git hooks 可绕过，不能冒充服务端强制门禁；基础包没有修改用户任何 GitHub 设置或 workflows。

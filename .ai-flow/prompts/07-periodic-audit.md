# v4.0 手工阶段审计

仅在用户手工要求时执行，本提示词不创建定时任务、不自动启动 Codex 或 GLM。读取近期已集成变化和真实验证，检查重复实现、未用代码、架构越界、数据流不一致、竞态、错误处理、类型漏洞与测试盲区。

先查现有 Issues/未合并 PR；确认问题须有证据、影响和可验收边界，按语义任务复用/创建必要 Issue。每个新 Task 同样必须写 L/R、Recommended implementer、Execution mode；Goal 中同步汇总。不要为报告好看无限制造低价值重构，也不顺手实施未授权范围。

给优先级/依赖和用户转交 Codex 的一句话。无权限写入则明确待发布摘要。人工跨工具启动权、balanced 路由和 reviewer 子代理门禁不变。

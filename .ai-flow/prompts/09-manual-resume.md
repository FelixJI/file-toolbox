# v4.0 手工继续 / 中断恢复

用户显式让本会话继续时才执行。先读 Issue 当前阶段、最后有效 GLM Handoff/结果、reviewer 子代理评论和最新 Git/PR/CI；旧聊天、旧 runner runtime 与 PID 不是恢复指令。

检查是否仍有实施写入者、当前分支/SHA 与 dirty 归属，以及 commit/push/建 PR/合并是否已生效。不得重放已完成操作、覆盖用户修改、删除锁文件或强推恢复。

等待条件未解除且真实阻塞后续时，报告准确状态/恢复条件并停止；不循环轮询。若还有不依赖该条件、属于当前主体授权范围的安全工作，先继续完成。

当前 Codex 能处理的技术问题连续处理；确需 GLM 才建立 Handoff 让用户手工启动。达到 REVIEW_READY 时由 Codex 自动启动 reviewer 子代理，不作为人工恢复边界。定制旧工作流仍在自动调度时先安全停止并完成迁移，不自动兼容旧协议。

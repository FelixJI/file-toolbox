# v4.0 手工继续 / 中断恢复

用户显式让本会话继续时才执行。先读 Issue 当前阶段、最后有效交接/结果/审阅评论和最新实际 Git/PR/CI；旧聊天、旧 runner runtime 与 PID 不是恢复指令。

检查是否仍有写入者、当前分支/SHA 与 dirty 归属，以及 commit/push/建 PR/合并是否已生效。不得重放已完成操作、覆盖用户修改、删除锁文件或强推恢复。

等待条件未解除且它真实阻塞后续时，报告准确状态/恢复条件并停止；不循环轮询。若还有不依赖该条件、属于当前主体授权范围的安全工作，先继续完成。条件解除后继续本阶段已授权工作；合并依赖必须核对远端事实与新基线。

由当前 Codex 处理技术问题，并在 next_actor 仍为当前会话时连续执行；只有转施工者或进入独立审阅等 actor 变化时才由用户手工启动下一侧。定制旧工作流仍在自动调度时先安全停止并完成迁移，不自动兼容旧协议。

# v4.0 Codex：复杂实施

读取当前任务合同、适用规则和真实分支/工作区，确认单一写入者后建立基线与最小复现。按必要 checkpoint 完成架构/状态/并发/数据边界等复杂工作；关键判断写 PR，不扩大目标，不做无关重构。

保持兼容与安全，补与变更相匹配的回归、集成、恢复/迁移测试。实际命令、cwd、退出码、AC 证据写清；未知或未跑不当通过。真实数据/部署另行授权。

同根因最多两轮有依据失败后无进展则止损，写复现和可行路径。配额/权限问题不授权换账户或放开沙箱。

精确暂存/提交当前任务文件，必要时更新 Draft PR；不提交本机报告。内部实现 checkpoint 结束后，若 next_actor 仍是当前 Codex，就继续下一项当前授权工作，不生成自我重启提示词。只有实现/验证已到正式独立审阅边界时才输出手工开启独立 Codex reviewer 的短句并停止；剩余明确施工且确需换 worker 时才输出三句交接。不自动调用其他 actor，也不在原对话正式批准。合并始终留给用户。
